Aegis browser collector

Track projects, not private prompts

After one-time consent, Aegis watches open Claude and ChatGPT conversations and syncs their project, title, message count, and estimated token volume automatically.

What leaves this browser Provider/project IDs and names, conversation ID/title/URL, counts, estimates, and a SHA-256 change digest. Prompt and response text, cookies, and site session tokens are never sent.

Web subscriptions do not expose authoritative per-message token usage or API cost. Aegis marks these figures as estimated / pool, so they cannot be mixed with billed API dollars.
